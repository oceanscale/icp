# LeadCard

A ficha de um lead dentro de uma etapa do funil.

- `name`, `company`, `value` ("R$ 4.800"), `days` (dias na etapa).
- `late`: troca o tempo por "Atrasado · 6d" em `danger`.
- `tag` e `tagTone` (`green`, `danger` ou padrão azul): canal ou próxima ação ("Cold call", "WhatsApp", "Break-up").
- Este app não é CRM: o LeadCard ilustra o desenho do funil e da cadência, não guarda histórico de contato.
