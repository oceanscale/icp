# CreativeCard

A sugestão de criativo e copy para Ads: formato, fase do funil, foco, headline, copy, CTA e a pauta para quem vai produzir.

- Faixa superior: `week` ("Semana 41"), `platform` (Meta, Google, LinkedIn, TikTok), `placement` (Feed, Stories, Search), `status`.
- `format` ("Carrossel 5 cards") e `ratio` (`1:1`, `4:5`, `9:16`, `1.91:1`, `16:9`), desenhado como moldura tracejada.
- `stage` (Topo, Meio, Fundo) e `focus` (Dor, Prova, Oferta, Objeção) viram chips.
- `headline`, `copy` (quebras de linha respeitadas), `cta`, `brief` (o criativo a produzir, rotulado "Criativo").
- `children`: ações ("Copiar copy", "Gerar variação").
- Um CreativeCard por ideia; as pautas de uma semana ficam empilhadas sob o título da semana.
