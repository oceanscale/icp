# Note

Bilhete fixado com alfinete, em letra de mão: a dica do detetive ao lado do conteúdo.

- `children`: uma ou duas frases curtas. Mais que isso vira parágrafo, não bilhete.
- `title`: rótulo opcional em caixa alta ("Dica do detetive").
- `pin`: `blue` (padrão) ou `green`; `tilt={false}` para alinhar.
- No máximo dois bilhetes por tela. Nunca coloque dado do cliente que precise ser copiado num Note: a letra de mão é para comentário.
