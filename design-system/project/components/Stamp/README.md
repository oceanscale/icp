# Stamp

Carimbo de status, sempre com palavra, inclinado em `tilt-stamp`.

- `tone`: `blue` (em andamento), `green` (resolvido, confirmado, dentro da meta), `ink` (confidencial, neutro), `danger` (urgente, acima do orçamento).
- `tilt={false}` deixa reto: use dentro de cartões pequenos e no `Readout`.
- `children`: uma a três palavras. O CSS põe em caixa alta.
- Um carimbo por ficha. Carimbo não é botão e não é clicável.
